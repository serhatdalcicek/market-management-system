MARKET - KURULUM

1. build_windows.bat dosyasini calistir.
2. Bilgisayarda Python yoksa Python 3.11 veya 3.12 kur.
3. Setup.exe olusturmak icin Inno Setup 6 kur:
   https://jrsoftware.org/isinfo.php
4. build_windows.bat dosyasini tekrar calistir.
5. installer klasorunde MarketSetup.exe olusur.
6. Arkadasina SADECE MarketSetup.exe dosyasini gonder.
7. Arkadasin MarketSetup.exe -> Ileri -> Ileri -> Kur adimlarini takip eder.
8. Kurulum bitince masaustunde Market kisayolu olusur.

Veriler lokal tutulur. Program kapaninca veya PC yeniden baslayinca kayitlar silinmez.
Yedek almak icin programdaki Yedek Olustur butonunu kullan.
